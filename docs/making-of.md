# 人物はAI、スマホ操作はコード。48秒の紹介動画を作った方法

LINEの会話を見ていたら、いつの間にか僕のX紹介になっている。そんな48秒の動画を作りました。

制作はChatGPT Work上で進め、人物はHiggsfieldのMiniMax H3、スマホ画面はRemotionで組み合わせています。

## 1. 参考動画を「操作」まで分解する

まず参考動画から、会話の流れ、文字入力、アプリ切り替えのタイミングを分析。フレーム画像でも画面の比率を確認しました。

今回の台本は「最近、誰を見てるの？」→Xを検索→プロフィールURLをコピー→LINEに貼り付け→相手もフォロー、という流れです。

## 2. 人物のカットをMiniMax H3で生成

冒頭は、若い成人女性が手でレンズを覆い、手を引いて顔を寄せる動きに。最初の一瞬で目を止めてもらうため、静かな立ち姿ではなく動きから始めました。

9:16・2Kで6秒の素材を生成し、冒頭に必要な部分を使っています。

## 3. スマホ操作をRemotionで再現

Remotionは、コードで動画を作れる仕組み。今回のスマホ画面は画面収録ではなく、UIを組んでアニメーションさせています。

こだわったのは、文字が出る前後の動きです。

- かな入力→変換候補→確定→送信→入力欄が空く→既読
- アプリが縮む→隣のカードへ移る→全画面に戻る
- URLのコピー→貼り付け→リンクカード表示

アプリ切り替えは27フレーム、0.9秒。縮小・横移動・拡大に合わせて、角丸や影も変えました。

## 4. 細部を直して、音と合わせる

最初はスマホ画面を大きくしすぎたので、参考元を測り直して黒い余白を確保。キーボードと会話欄の比率も修正しました。

LINE・Xなどは実際のアプリアイコンを使用。プロフィール画像は左側の相手から届く流れに直し、ピアノBGMと通知・入力・送受信音を重ねました。

最後に48秒・720×1280・30fpsで書き出し、主要場面の文字や画面位置を確認して完成です。

今回いちばん効いたのは、人物の自然な動きと、文字・UIの正確な動きを別々に作ったこと。入力の「間」や送信後の反応まで作ると、スマホを操作している感じがぐっと出ました。
